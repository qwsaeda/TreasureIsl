## 桌面（Windows macroquad）

### 缩放模式
- [ ] `Smooth`：拖窗口到 463×578，画面连续缩放，无马赛克跳变
- [ ] `Integer`：同窗口，画面跳变为 1× 或 2×（非 1.704×），像素锐利
- [ ] `Integer` + 极小窗口（100×130）：画面为 1×，不变形
- [ ] 切换缩放模式无需重启（热切换可选，当前版本重启生效即可）

### 横竖屏
- [ ] `Portrait`（默认）：176×220 竖屏，窗口拉宽出现 letterbox（上下黑边）
- [ ] `Landscape`：逻辑宽高交换为 220×176，窗口拉窄出现 pillarbox（左右黑边）
- [ ] 横竖屏切换后命中判定（点击菜单项）位置正确

### 虚拟方向键
- [ ] 触摸屏（或鼠标模拟）点按上/下/左/右虚拟键 → 对应菜单移动
- [ ] 点按虚拟键外 1px → 不触发
- [ ] 四个键互不重叠（触摸任意两键同时 → 两个方向同时生效）

### 手势
- [ ] 轻触（位移 < 20px）→ 识别为 `Tap`，触发菜单确认
- [ ] 右滑（起点→终点 dx > 20）→ 识别为 `SwipeRight`
- [ ] 左滑 → `SwipeLeft`；上滑 → `SwipeUp`；下滑 → `SwipeDown`
- [ ] 无按下记录时释放 → 不产出手势

### 按键自定义
- [ ] 默认绑定：↑↓←→ + Enter + Esc 均可操作
- [ ] 将 "up" 改绑为 W 键后，按 W 上移菜单（W 替代 ↑）
- [ ] 未绑定动作（如 "fly"）查询返回 `None`，不影响默认行为

## 浏览器（WASM）

- [ ] canvas 拉伸到不同宽高比，命中判定无偏移（P4-2 复测）
- [ ] `Integer` 缩放在高分屏（Retina）下无糊化
- [ ] 触摸虚拟方向键可用（移动端浏览器）
- [ ] 触摸滑动方向正确（`SwipeUp/Down/Left/Right`）
- [ ] 横竖屏：手机横放/竖放时逻辑宽高正确交换
