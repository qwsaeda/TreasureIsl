# scripts/tmp/ —— 一次性改写脚本落地位置

**用途**：本目录是**唯一**允许放"一次性改写脚本"的位置（迁移、清库、批量重写等
**改完仓库即删**的活）。用完立即删除，**不得留到任务结束**。

## 硬规则

1. **反复要跑的 / 结论要进文档的 / 别人也会用的 ⇒ 不许放这里** ⇒ 提升为
   `scripts/` 正式工具，并按 [`../../docs/process/14_tooling_catalog.md`](../../docs/process/14_tooling_catalog.md)
   §1.2 登记（幂等 + 只读模式 + 非 0 退出 + 台账 + 速查表 + 自动对账）。
2. **不许写到仓库外**（系统临时目录、桌面等）—— 仓库外的脚本绕开台账登记与
   门禁对账，等于没写进项目。
3. **任务结束时本目录必须为空**（本 README 除外）—— `doccheck2` 第 27 项
   `check_tooling_contract` 会把残留判为 FAIL。
4. 本目录里的脚本**不进产品代码**，也不做长期依赖。

## 反面教材（EXP-113 / S21 实证）

同一段逻辑（批量登记资产 + 并行生图 + 抠图）因为 `ui_assets.py` 只有单资产入口，
被写成临时脚本搬到仓库外临时目录 ⇒ 台账无登记、门禁查不到、事后无法复用。
正解 = 补齐工具缺口（`scripts/ui_asset_batch.py` + `assets/ui_batches/*.json` 规格）。
