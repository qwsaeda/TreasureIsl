# 一次性逆向探针（Archived Probes）

本目录存放**已跑完、结论已回写**的一次性分析脚本。它们不是流水线的一部分，`gate.ps1` 不调用，文档也不再引用。

## 保留它们的理由

每条结论的**可复现入口**。当 `docs/facts/<分卷>.md` 里的某条结论被新证据推翻时，需要能重跑当初的探针做对照 —— 这是 `docs/experience/` 里反复出现的教训（样本量不足就下结论、单图规律换第二图就崩）。

## 不要在新任务里引用这些脚本

新任务的分析脚本应写在 `scripts/` 顶层并带任务号前缀（如 `s1_12_*.py`），跑完后随结论一起归档到本目录。
