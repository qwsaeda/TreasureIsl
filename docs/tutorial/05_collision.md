## 核心概念

### 为什么需要碰撞检测

**生活类比：你在街上走，不能穿过墙壁**

```
想象你在城市里走：
  你前面有栋房子 → 你绕过去（碰撞）
  你前面是空地 → 你直接走过去（没碰撞）

  碰撞检测 = 判断"我能不能走到这里"
```

**游戏中的应用**：
```
地图碰撞：玩家是否能走到某个格子（墙/水/建筑）
UI 碰撞：点击是否命中按钮/选项
战斗碰撞：子弹是否击中目标
```

### AABB（Axis-Aligned Bounding Box）

**生活类比：两个纸箱是否叠在一起**

**① 重叠（相交）**

```
        x →
      0      5      10
    0 ┌─────┬─────┐
      │     │  A  │        A: (0,0) 10x10
    5 ├─────┼─────┤        B: (5,5) 10x10
      │ B   │     │
      │     │     │
   10 └─────┴─────┘
          ↑
      B 的左上角落在 A 里面 → 重叠 ✅

  判断（A 的右/下边 > B 的左/上边）：
      A 右 = 0+10 = 10 > B 左 = 5     ✓
      A 下 = 0+10 = 10 > B 上 = 5     ✓
      → 两边都成立 → 重叠
```

**② 刚好挨着（边界情况，容易写错）**

```
      0      10     15
    0 ┌──────┬─────┐
      │  A   │     │        A: (0,0) 10x10
   10 ├──────┼─────┤        B: (10,0) 5x5
      │      │  B  │
   15 └──────┴─────┘

      A 右 = 10，B 左 = 10  →  10 > 10  不成立 ❌
      → 不重叠（只是贴边，没压上去）
```

**③ 完全分开**

```
    0 ┌──────┐
      │  A   │
   10 └──────┘
   20        ┌──────┐
             │  B   │              → 明显不重叠
   25        └──────┘
```

**判断方法（4 次比较定胜负）**：
```
  重叠 = A右边 > B左边  且  A左边 < B右边
     且  A下边  > B上边  且  A上边 < B下边
```

**特点**：
- 计算极快（4 次比较）
- 只能检测矩形，旋转后需要更复杂的方法
- 适合：UI 点击检测、简单物体碰撞

### 圆形碰撞检测

**生活类比：两个泡泡是否碰到一起**

```
  泡泡 A: 圆心 (0,0) 半径 5          泡泡 B: 圆心 (8,0) 半径 5

          .-----.
       .-'  A    '-.
      /    ●(0,0)    \              .-------.
      \               /           .-'   B    '-.
       '-.         .-'         .'     ●(8,0)     '.
          '-------'            /                    \
                              |  <---- 8 ---->     |
                              \                    /
                               '-.              .-'
                                  '------------'

      圆心距离 = 8
      半径和   = 5 + 5 = 10
      8 < 10  →  碰到了 ✅
```

**判断（用平方，避免开根号）**：
```
      距离² < (半径和)²
      8² < (5+5)²
      64 < 100  →  碰到
```

```
      再拉开一点：B 挪到 (12,0)

          .-----.                        .-------.
       .-'  A   '-.                    .'    B     '.
      /    ●       \                 .'      ●       '.
      \             /                 '--------------'

      距离 = 12   半径和 = 10   12 > 10  →  没碰到 ❌
```

**特点**：
- 计算快（1 次距离计算）
- 适合：圆形物体（球、子弹、角色）

### 网格碰撞检测（Tile-based）

**生活类比：棋盘上的棋子能否走到某个格子**

```
    0  1  2  3  4        0 = 空地，可以走
  0 ┌──┬──┬──┬──┐        1 = 墙，不能走
  1 │  │  │  │  │        P = 玩家
  2 │  │██│██│  │        ▓ = 移动后想去的位置
  3 │  │██│  │  │
  4 │  │  │  │  │
  5 │  │  │▓█│  │
    └──┴──┴──┴──┘

  玩家在 (0,0)，想走到 (4,3)
  查表：地形[3][4] = 1（墙）  →  不能走 ❌

  碰撞检测 = 一次查表，比任何几何计算都快
```

**邻格查询（地图移动的常见写法）**：

```
    玩家 P 在 (2,2)，问四个方向能不能走

      ┌───┬───┬───┐
      │   │ N │   │      N (1,2) = 0 → 上边能走
      ├───┼───┼───┤
      │ W │ P │ E │      W (2,1) = 0 → 左边能走
      ├───┼───┼───┤      E (2,3) = 0 → 右边能走
      │   │██│ S │      S (3,2) = 1 → 下边是墙，不行
      └───┴───┴───┘

  ★ 只需查 4 格，不用算碰撞
```

**特点**：
- 2D 游戏最常用
- 查询极快（1 次查表）
- 适合：地图移动、战棋游戏

### 空间划分优化

**生活类比：找城市里的商店**

```
  暴力法：走遍城市每个角落找商店

    ┌─┬─┬─┬─┬─┬─┬─┬─┐
    ├─┼─┼─┼─┼─┼─┼─┼─┤
    │✕│ │ │ │ │ │ │✕│      每个物体两两比一遍
    ├─┼─┼─┼─┼─┼─┼─┼─┤      10 个物体 = 45 次比较
    │ │ │ │ │ │ │ │✕│      100 个物体 = 4950 次比较 😱
    └─┴─┴─┴─┴─┴─┴─┴─┘

  网格法：把城市切块，只搜附近的

    ┌─────┬─────┬─────┐
    │     │  ▣  │     │     ▣ = 只搜索所在块
    │     │✕ · ·│     │     ✕ = 本块的物体
    ├─────┼─────┼─────┤     搜索范围从"全城"缩到"1 块"
    │     │     │     │
    ├─────┼─────┼─────┤
    │     │     │     │
    └─────┴─────┴─────┘
```

**复杂度对比**：

```
  100 个物体：
    暴力   4950 次比较
    网格   ~100 次（只查附近几块）
```

**常见方法**：

| 方法 | 生活类比 | 适合 |
|---|---|---|
| 暴力检测 | 走遍城市每个角落 | 物体少（< 100） |
| 网格划分 | 按区域搜索 | 2D 游戏 |
| 四叉树 | 递归细分区域 | 2D 动态场景 |
| BVH | 分层包围盒 | 3D 场景 |

## 常见坑

| 坑 | 原因 | 避免 |
|---|---|---|
| 碰撞检测遗漏 | 只检测当前位置，不检测路径 | 移动前检测目标位置 |
| 碰撞体太大 | 碰撞体包含透明区域 | 碰撞体用实际可见区域 |
| 浮点精度问题 | 坐标用 float 比较 | 用整数网格坐标 |
| 每帧全量检测 | 没有空间优化 | 网格划分或四叉树 |
