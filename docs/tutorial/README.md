# 游戏开发入门教程

> **目标读者**：有编程经验但无游戏开发经验的开发者。
> **学习方式**：每章独立阅读，按顺序学习，紧密绑定本项目（TreasureIsl）实际代码。
> **预计总时长**：15-20 小时（含实践练习）。

## 学习路径

```
01 游戏循环 → 02 状态机 → 03 坐标系 → 04 时间步长
→ 05 碰撞检测 → 06 输入系统 → 07 渲染基础
→ 08 ECS vs 组件化 → 09 业务/渲染分离 → 10 项目架构
```

1. **学习目标** — 学完应能做什么
