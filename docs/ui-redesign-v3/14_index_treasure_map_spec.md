# 14 · index 首页横版重设计「羊皮藏宝图 + 绳挂木牌」规格（S39 定案）

> **本文件 = index 首页**横屏（1920×1080）**重设计的版面 / 交互 / 资产接线单一事实源**。
> 数据源 = `assets/data/scenes.json` 的 `index.landscape` 段（横屏原语）+
> `assets/ui_manifest.json` 登记的 16 件组件资产。
> 竖屏（1080×1920）沿用 S38.1 罗盘环版 ⇒ 见 `09_index_compass_spec.md`（**竖屏**单一事实源）。
>
> 触发：用户 2026-11-05「index 现代化重设计：以原版布局为参考骨架（标题+角色+菜单），
> 美术全现代化（禁像素复刻）」+「**游戏主流是横版**」+「**可以多贴图分层渲染，不必 AI 一次生全**」
> +「**这个界面可以把元素都拆分出来再组件加载渲染**」+「**标题应该融合到背景里**」
> +「**换 UI/换地图应该零改动 Rust 代码**」（question 工具拍板留痕）。

## 0. 设计意图（终稿）

- **骨架沿用原版**：标题 + 角色 + 菜单（现代美术重做，非像素复刻）。
- **满屏羊皮藏宝图**为底（与 `main_map` v4/v6 海图主题统一）：做旧羊皮 + 手绘海岛 + 红色虚线航线
  + X 宝藏标记 + 罗盘玫瑰 + 帆船/鲸鱼/海怪 + 骷髅徽章。
- **标题 = 写在图上的墨**（不是「贴上去的牌子」）：白底狂草「金银岛」以**正片叠底**融入羊皮图，
  **逐字变色**（金 = 鎏金墨 / 银 = 冷银墨 / 岛 = 铜绿锈墨），干笔飞白保留。
- **人物层**：冷峻红头巾海盗（眼罩/弯刀）+ 蹲坐熊猫海盗（油灯）围看展开藏宝图 + 金宝箱（互动叙事）。
- **菜单 = 绳挂木牌**（右列 6 块）：木纹牌面 + **烙印文案** + AI 图例徽章图标；首项金边高亮。
- **拆件组件化**：所有元素 = 独立资产组件（底图 / 标题烘焙 / 人物层 / 绳 / 6 木牌 / 选中金边 / 6 图标），
  运行时按组件加载渲染（**不** AI 一张包圆）。

## 3. 交互契约（不变）

- 命中 = 拾取层 `pick_key=1` + `pick_index=0..5` ⇒ `ti-app` `IndexScene::on_hit` **零改动**：
  选中该项并立即执行（`Confirm`）。
- 键盘 ↑↓/Enter 走 `GameInput`（`MENU_COUNT=6`，未改）。
- 选中态 = 数据层 `when="selected"`（金边叠加层）⇒ **选中变化须重建 UI 层**
  （壳 `chrome_ui_system` 的 `sel_key` 含 `menu_selected`）。
- **数据契约（S39.0 实测 bug 修复）**：`ui_layer="bevy_ui"` 且带 `when="selected"|"normal"` 的原语
  的 `item` 字段 = 所属菜单项序号（`pick_index` 对齐值 0..5，**非 -1**）；`when="selected"`
  过滤读的是 `item`（不是 `params.pick_index`）⇒ `item=-1` 导致所有选中态原语被滤掉
  （木牌/图标/金边全不渲染，J1 非黑 ≥90% 假达标、菜单缺失）。无 `when` 的原语不要求
  （saveload 等列表场景 `item` 缺省）。`validate_data.py` `check_scenes_item_contract` 兜底
  （`ui_layer=bevy_ui` 且 `when∈{selected,normal}` 的原语 `item ≥ 0`）。

## 4. 数据化架构（S39 一次性重构：换 UI 零 Rust 改动）

**问题**：此前 index 菜单的**版面**（环形布局数学 + 硬编码图标数组 `ICONS`）写在 Rust 里 ⇒
换一次首页视觉就要改 Rust（违背「UI / 地图 / 逻辑分离」）。

**解法**（本次一次性，之后不再需要）：

1. `ti-engine::ui::build_data_chrome` = 通用「原语 → `bevy_ui` 节点」通道
   （`image` / `icon` / `text` / `rect`；`rect` 按**设计空间**换算 `%` ⇒ resize 真重排；
   `when=selected|normal` 过滤；`pick_key` 挂 `PickTarget`）。
2. 壳侧 `build_index_chrome` = 原语 → `DataChromeItem` 转换（解析 i18n）+ 调用通用渲染器。
3. **删除** Rust 罗盘环（`index_ring_params` + 旧 `build_index_chrome` + `RING_LABEL_*` 常量）。
   竖屏罗盘环**由数据还原**（数据 rect 与旧环布局逐格一致，实测 468,498 / 814,698 / … 全等）。
4. 竖屏补 `kind="rect"` 铭牌底原语（`brass_dark`）⇒ 保住原标签底视觉。

⇒ **此后 index 首页换视觉 = 改 `scenes.json` + 换资产 = Rust 零改动**（唯一例外：若引入
新**交互形态**才需逻辑侧扩展）。
