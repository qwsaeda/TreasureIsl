## 0. 设计意图

- **整屏 = 摊开的羊皮海图**（沿用 v4 `chart_full`），主视觉 = **中央一座玩家据点大岛**（可点击）
  + **四周一圈大富翁式「格子卡片」**（每格 = 一个领地/功能点，卡面 = 岛型插画 + 归属条）。
- **每格可读**：卡面放大到 ≥96×120（v4 节点牌只有 ~30px ⇒ 类型不可辨，这是「看不出是什么岛」的根因）；
  卡面按岛型配色（10 色）+ 图标 + 归属条（自己的=金，AI 的=其席位色，无主=素羊皮）。
- **一眼看出「谁的地」**：每张卡底一条**归属色带**（自己的=金，AI 的=其席位色，无主=素羊皮）；
  中央据点岛 = 自己的大本营（点击 → 据点菜单）。
- 规则层（占格 / 交钱 / 攻占 / 加固 / AI 回合）见 `business/territory.md`；本文件只管**画什么、点哪**。

## 2. 环形格子环几何（运行时计算，`board.json` 单一事实源 = 31 格）

| 项 | 值 | 说明 |
|---|---|---|
| 环心 | `(540, 780)` | 竖向略偏下（顶部让给 HUD，底部让给 CTA） |
| 环半径 | `R = 474` | 卡中心落在此圆上 |
| 卡片尺寸 | `96 × 120` | 周长切分：`2πR/31 ≈ 96` ⇒ 相邻卡相切不重叠 |
| 卡 i 角位 | `θ_i = -90° + i × (360°/31)` | `i=0` = 顶部（起点），顺时针 |
| 卡 i 中心 | `(540 + R·cosθ_i, 780 + R·sinθ_i)` | — |
| 环外接框 | `x 18..1062`，`y 246..1314` | = `world_canvas` 焦点矩形 |
| 中央据点岛 | `{160,400,760,760}`（正方形，圆心 540,780 与环心重合） | 内切圆半径 380 < 环内径 414 ✓ 留 34px 空隙 |

**卡面构成**（自内向外）：
1. 卡底（羊皮 + 黄铜细边）；
2. **归属色带**（卡底部 16px：无主 = 素羊皮 / 自己 = `gold_warm` / AI 席位 = 该席位色）；
3. **岛型插画**（`isle_<isle_id>.png`，96×120 内居中，等比缩放）；
4. **卡名**（`strings.json` 的岛名/功能名，10pt，居中，1 行）；
5. **加固等级角标**（自己的领地才显示：`Lv.2` 之类，8px 角标）;
6. 功能格用既有 `node_event/card/treasure/boss/start.png` 插画 + 同款卡底。

**唯一例外**：BOSS 卡 = 无畏号要塞（`isle_boss_fort.png`），卡面加骷髅角标 + 边框加粗（黄铜双线）。

## 4. 信息架构（`scene_manifest_v3.json` main_map 段）

- **mood** = `world_explore`（N2：focus.anchor = `world_canvas`；rhythm.rule = `world_first_hud_corner`）；
- **focus** = `world_canvas`，`bbox_pct {x:1, y:12, w:97, h:56}`（N8 对账，见 §5）；
- **rhythm.beats**（权重和 = 1.0，beats[0] = focus.anchor，权重 ≥ 0.30）：

| beat | weight | y_pct | 语义 |
|---|---|---|---|
| `world_canvas` | 0.55 | 40 | 环形格子环（主焦点） |

## 5. 门禁耦合点（改版面必须同改，否则门禁 FAIL）

| 门禁 | 锚点 | 本规格目标值 |
|---|---|---|
| N8 | `scenes.json` `focus_anchor.bbox` ≡ `manifest.focus.bbox_pct × (1080,1920)` ±1px | `{16,248,1048,1064}` ↔ `bbox_pct {x:1,y:12,w:97,h:56}`（1×10.8=10.8→**16**? 见下） |
| N3（焦点面积 ≥20%） | `w×h/100` | 97×56 = 54.3% ✓ |
| N4 | beats[0] = anchor，权重 ≥0.30，和 = 1.0 | `world_canvas` 0.55 / 和 1.00 ✓ |
| N6 | 常驻 HUD ≤ 3 | 2 ✓ |
| 8pt | 非豁免键 8 整除 | §3 全过 |
| 原语闭集 | 7 种（rect/text/icon/grad/glow/disc/image） | 只 `image` + 运行时，**不新增原语 kind** |
| 资产登记 | `image` 原语 asset 必须入 `ui_manifest.json` | `chart_full`/`hud_plaque`/`btn_spin`/`deck_plaque`/`island_home` 全部登记（S27.2 生成） |

> **N8 换算细则**：`bbox_pct` 取 `round(pct/100 × 1080)`、`round(pct/100 × 1920)`，容差 ±1px。
> `world_canvas {16,248,1048,1064}` ⇒ `x = 16/1080 = 1.48%`、`y = 248/1920 = 12.92%`、
> `w = 1048/1080 = 97.04%`、`h = 1064/1920 = 55.42%` ⇒ 写入 `bbox_pct {x:1, y:12, w:97, h:56}`
> （回算 1×10.8=10.8→11 vs 16 = 5px 差 ⇒ **超 ±1 容差** ⇒ `bbox_pct` 须按 §5 备注在
> `scenes.json` 里直接写**像素换算后的整数值** `bbox_pct` 口径以 `check_scene_narrative`
> 的实际换算式为准，落码时由 `scripts/layout_spec_check.py` 复算并回写，**不得手抄**）。

## 6. 交互契约（`main_map.rs` on_touch；命中判定与渲染同坐标系，`EXP-067`）

| 命中区 | 动作 | 语义 |
|---|---|---|
| `deck_spin {408,1336,264,264}` | `GameInput::Spin` | 摇骰前进（主操作，最先命中） |
| `deck_trade` / `deck_sell` / `deck_build` | `TradeBuy(1)` / `TradeSell(1)` / `Build(Castle)` | 沿用 v4 |
| `island_home {160,400,760,760}` | `Landmark(1)` | **据点菜单**（建造 / 造船 / 贸易 / 升级本家） |
| 环形卡 i（卡矩形内） | 见下 | 点卡 |
| 其余 | 无动作 | 滑动 = 无（S19 收口） |

**点卡语义**（卡 i 命中 = 屏幕坐标反投影到最近卡中心，距离 ≤ 卡半对角线）：
- 展示**卡信息签**（z9）：岛型名 + 归属（无主 / 你 / 某 AI 席位）+ 加固等级 + 本格产出/过路费；
- **只读预览，不移动**（移动唯一 = 摇骰）；
- **归属为别人的卡**：信息签上直接给出两个可选动作按钮（**交钱** / **攻占**）⇒ 走
  `business/territory.md` §4 分支；
- **无主卡**：信息签给出「进入副本」按钮 ⇒ 进副本场景；
- **自己的卡**：信息签给出「升级加固」按钮 + 本格产出领取。

**摇骰反馈**：落格后目标卡脉冲高亮 1 拍 + 提示签条（z9）+ 骰点文本（CTA 上沿）。
