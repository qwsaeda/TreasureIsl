进入/退出（证据）：
- **进入**：主菜单「说明」`sub_41354` case 3/4（行 188-252）→ `operator new(0x830) + sub_3F8FC(help.map, 总页数, 页表)`；据点 `sub_2101C` case 1（行 1711-1796）→ `operator new(0x610) + sub_462DC(msgl.Map)`；`sub_29110` case 5（行 1454-1519）→ `operator new(0x48C) + sub_43400(information.map)`。
- **退出**：`sub_3F4E4`/`sub_4085C` 的 `a3==27` → `sub_3DC04(v3[1], 6/8)` 回到 index 场景；`sub_11E38` case 10/20（行 29-42）→ `v3[318]` 对话框 vtable[0] 传 1（销毁）后 `v3[317]=0`、`v3[318]=0`（**推测** = 对话框对象释放 + 槽位清零，回到主地图帧更新）。

翻页边界规则（定死 oracle 行为，`sub_4085C` 行 35-61/117-126 证据 + 边界语义）：
- **NextPage（事件码 38/40）到最后一页 → 保持最后一页（`sub_4085C` 行 54：`v13 != 总页数-1` 才 +1，否则不翻页）**；
- **PrevPage（事件码 37）到第一页 → `sub_3F4E4` 行 121-124：页码==1 时回总页数（循环），`sub_4085C` 行 40-43：页码==0 时回总页数-1（循环）**。两条路径不一致（3F4E4 是 1..N 回绕，4085C 是 0..N-1 回绕）——oracle 取**定死一条**：页码 `page ∈ 0..total-1`，NextPage 到末页 → 保持（`page` 不变），PrevPage 到首页 → 回末页（`page = total-1` 循环）。**依据**：`sub_4085C` 的 0 起页码（`v3[22]` 初值 0，行 78 `off_6F32C[v3[22]]` 索引 0 有效）+ 行 40-43 的「0 回 total-1」循环语义，`sub_3F4E4` 的 1 起页码视为其 `v3[13]` 私有偏移（1 = 首页），两者归一到 0 起页码后行为一致。
- **Close（`a3==27` 返回）→ 界面关闭（oracle 状态 `None`）**；
- **Open（新 kind）→ `page = 0`**。

`total_pages` 常量（推测）：exe 侧 `sub_4085C` 的总页数 = `(v3[14] - v3[13]) >> 2 - 1`（行 43/54/117），即**由场景对象 `v3[14]-v3[13]` 差值动态计算**，无固定常量。oracle 层以 spec 常量建模：help 类（`sub_41354` case 3 传 `a4=3`）→ `total_pages = 3`（case 4 传 `a4=2` → `total_pages = 2`，两入口对应不同总页数档）；msgl/msgm/msgs/information 类无翻页（`sub_4661C` 的 `a3=0` 翻页标志，`sub_12278`/`sub_12434` 传 `a3=1` 但条目索引 `a4` 固定）→ **`total_pages = 1`（推测：单页对话框，翻页标志置 1 仅表示「有翻页按钮可点」而非多页）**。oracle 常量表：

|---|---|---|
| `Msgs` | 1 | 推测：`sub_2101C` 行 2213 无翻页上下文 |
| `Msgl` | 1 | 推测：`sub_42E74` 单页据点名 |
| `Msgm` | 1 | 推测：`sub_12278`/`sub_12434` 单页结果面板 |

## §e 缺口与未验证项

1. msgs/msgl/msgm 的「小/中/大消息」大小语义 —— 仅资源名差异 + 统一 0x610 对象布局推断，无 exe 注释证据；
2. `information.map` = 角色状态/信息界面 —— 由 `sub_43400` 独立 vtable `off_6F4FC` 推断，行 1470 无上下文文本；
3. `msgl`/`msgm`/`msgs` 的 `total_pages = 1` —— exe 侧 `sub_4661C` 翻页标志 `a3` 与条目索引 `a4` 的组合未逐点核对，oracle 定死单页；
4. `word_7E470`/`word_7D694`/`word_7D6F0`/`word_7D6D8`/`word_7D714` 的实际文本内容 —— 这些 `word_*` 全局宽字符串常量在 exe `.rdata` 段未逐字读取（BSS/初始化区布局未完整映射），oracle 层 `oracle_text_line` 以确定性占位文本建模，不声称还原原文；
5. `switchpage.pcx` 翻页按钮的精灵槽布局（`a1+522` 位图 + 16 色索引）—— `sub_645B4` 位图解码细节未逆向，oracle 只建模「翻页事件 → 页码状态」。
