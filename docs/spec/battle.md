## §c 战斗流程（回合制）

### 回合结构（推测）

exe 伪代码中 `sub_572E4` 仅完成场景 ctor，战斗回合逻辑分散在 `off_73A2C` vtable 的虚函数中（无独立伪代码导出）。

> **推测**：回合制流程（每回合双方各行动一次）：
> 1. 玩家行动：选兵种 → 造成 `atk` 伤害（确定性伪随机）；
> 2. 敌方行动：BOSS 反击 → 造成 `boss_atk` 伤害；
> 3. 判定：任一方 HP ≤ 0 → 结束，胜方 = 对方；
> 4. 重复直到胜方确定。
>
> 伤害公式（oracle 层确定性建模）：`damage = (seed.wrapping_mul(2654435761)) % (atk+1) + 1`，
> 无 rand 库，纯确定性（同 seed 同 atk 同结果）。
>
> 该公式为 oracle 占位（**推测**），exe 实际 RNG 归 S3.12 对齐。

### 胜负判定（推测）

- 玩家 HP ≤ 0 → `Enemy` 胜；
- 敌方 HP ≤ 0 → `Player` 胜；
- 同时归零（`atk` 足够大时）→ **推测**：先判玩家（玩家优势），`Player` 胜。
