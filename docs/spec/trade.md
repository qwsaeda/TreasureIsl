> **oracle 简化**：价格表为固定 5 项 `(goods_id, price)` 对，由 `sub_546E0` 初值 `a1[267..276]` = `[20,20,76,20,95,114,133,0]` 给出 5 组 (值, stock) 对。**推测** 实际价格由 `sub_445F4` 运行时查表（资源集），oracle 层用 `PriceTable.entries: Vec<(u32, u32)>` 建模固定价格，`oracle_price` 直接查表返回，不做行情波动（波动 = `sub_2101C` case 4 的 `rand()%22+1` 哈希，归 S3.12 RNG 对齐范围）。

### 行情波动（证据 + 推测）

`sub_2101C` case 4（行 2055-2060）：`rand()` → `LOBYTE(v821) = rand() - 22*(...) + 1`（即 `rand() % 22 + 1`）→ `sub_18704` 验证 → 结果码 3 时修正为 2。
**推测**：此哈希为「商品选择」而非「价格波动」——`rand()%22+1` 选 22 种货物之一，价格本身由 `sub_445F4` 固定查表。oracle 层不建模行情波动（固定价格表），`oracle_price` 直接返回表值。

## §c 买入/卖出结算（利润公式）

### 买入（证据，`sub_54D1C` a2=1，行 45-68）

```
price = sub_445F4(a1, buy_key[商品索引])   // 202/402/602/802/112
*(_DWORD*)(a1 + 4*idx + 1108) = price      // 槽价格
++*(_DWORD*)(a1 + 4*idx + 1108)            // 数量 +1
// 金扣减（行 99，a2=1 时 v5!=0 分支）：
*(_DWORD*)(a1 + 1024) -= *(_DWORD*)(v8 + 1112) * *(_DWORD*)v9
// 等价：gold -= price * qty（qty=1 时 gold -= price）
```

**oracle 公式**（直译）：
```
paid = price(gid)
profit = 0  // 买入不产生利润
gold_left = gold - paid
```

### 卖出（证据，`sub_54D1C` a2=0，行 144-165）

```
price = sub_445F4(a1, sell_key[商品索引])   // 102/302/502/702/902
*(_DWORD*)(a1 + 4*idx + 1108) = price
--*(_DWORD*)(a1 + 4*idx + 1108)            // 数量 -1
// 金累加（行 118，v5==0 分支）：
*(_DWORD*)(a1 + 1024) -= *(_DWORD*)(v12 + 1112) * *(_DWORD*)v13
// 等价：gold += price * qty（注意 exe 用减法符号，v12+1112=价格，v13=数量）
```

**oracle 公式**（直译，注意 `+1024` 为 i32 累加）：
```
gain = price(gid)
profit = gain - avg_buy_price(gid)   // 利润 = 卖出价 - 买入均价
gold_left = gold + gain
```

### 买入均价（证据，`sub_54D1C` 行 115-135/209-233）

```
// 总价值（行 225-229，卖出后重算）：
total_cost = Σ (slot[i].price × slot[i].qty) for i in 0..count
avg_price  = (total_gold_after - total_cost_other) / (total_qty - 1)
// 等价：均价 = (当前总金 - 其他货物总成本) / 剩余持有数
profit = price - avg_price（行 134/231，负值钳 0）
```

**oracle 简化**（固定价格表，单商品）：
```
avg_buy_price(gid) = 历史买入总成本 / 历史买入数量
profit = price - avg_buy_price（若 avg 未定义则 profit = price）
```

> **推测**：`sub_445F4` 的 key 值（202/402/602/802/112 买入，102/302/502/702/902 卖出）对应 `goods.lpk` 二进制表中的 5 种商品的价格槽；具体 key→商品名映射需对照 S1.6 goods 解析结果。**oracle 层用占位价格表 `[20, 76, 95, 114, 133]`（来自 `sub_546E0` 初值）**，S3.6 验收以固定价格表逐笔结算差分一致为准。

### 手续费（推测）

伪代码中**未见**独立手续费扣减——`sub_54D1C` 仅做 `gold ±= price × qty`。
**推测**：手续费为 0（无扣费），或已包含在买卖价差（买入价 > 卖出价）中。oracle 层不建模手续费。

## 推测点汇总

1. `sub_445F4` 的 key 值（202/402/.../902）→ 商品名映射 —— 需对照 `goods.lpk` 二进制表（S1.6 解析），oracle 层用占位价格表；
2. 行情波动（`rand()%22+1`）= 商品选择而非价格波动 —— **推测**，价格本身固定；
3. 手续费 = 0（未见独立扣减）—— **推测**，或含在买卖价差中；
4. `sub_546E0` 初值 `[20,20,76,20,95,114,133,0]` 为 5 组 (价格, 库存) 对 —— **推测** 字段解读；
5. 事件码 21（据点结算完成态）= 贸易入口前置 —— **推测**，需 S3.7 建造/城堡模块交叉验证；
6. `sub_445F4` 返回的 8 字节节点 `v6[6]`=key、`v6[0]`=price —— **推测** 字段布局（exe 侧资源集遍历语义）。
