# 内容设计 sheet（docs/design-sheets/）

一张内容（新地图 / 新岛类 / 新剧情）= 一张设计 sheet。模版与套用纪律见
[`../process/03_templates.md`](../process/03_templates.md) §8「内容设计 sheet 模版（Canvas 概念落地，S16.4）」。

目录约定：
- 文件名 = `<内容名>.sheet.md`（例：`m04_pirate_arc.sheet.md`）
- 四段式固定：A 业务定案 / B 数据 key 契约 / C 场景资源接线 / D 验收锚点（§8 模版原样）
- 本目录只放 sheet（设计段）；实现段走 §7 模块包任务书（`docs/process/05_module_parallel.md`）

本目录目前只有模版说明；`assets/maps/m04/` = S16.4 留下的空样例（31 格骨架 + 待填内容），
