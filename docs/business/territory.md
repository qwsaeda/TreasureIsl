> **本文件 = 领地/副本/对手机制（v5 主地图大富翁化）的业务规则唯一事实源**。
> 数值全部落在 `assets/data/balance.json`（本文件只写「哪个数、为什么」与公式结构）；
> 版面/坐标另见 [`../ui-redesign-v3/10_main_map_v5_spec.md`](../ui-redesign-v3/10_main_map_v5_spec.md)；
> 赛道与跨图推进见 [`progression.md`](progression.md)；战斗（VS）模型见 [`combat.md`](combat.md)。

> 落到这格可以进入副本；别人占领的可交钱或攻占；自己的领地可以升级加固——这就是原来的玩法」
> +「每局 4 个 AI 玩家」+「可以选至少一个玩家」。

> 本作本质是**大富翁式多人对局**（原版证据：5 角色各一份存档 `gl0~4.sav` + 各一枚棋子

> 最后存活者胜。§1 重写为 v3 口径。

## 1. 席位与对局结构（v3：2..5 人类热座 + 可配 AI 席）

| 项 | 规则 | 值来源 |
|---|---|---|
| 席位池 | 5 个角色（`panda` / `tichy` / `kidd` / `drake` / `katharina`），**每角色 = 1 席位** | `balance.selection.characters[].id` |
| 人类席 | 玩家在选角界面勾选 **2..5** 名角色作为**人类席位**（热座轮流操作） | `balance.selection` |
| AI 席 | **席数可配** `0..=(5 - 人类席数)`；未被勾选的剩余角色按 `index` 升序补 AI 席 | `balance.selection` |
| 典型局 | 2 人类 + 3 AI / 5 人类纯热座 / 2 人类 + 1 AI 均合法 | 设计意图 |
| 回合顺序 | 席位按 `characters[].index` 升序循环（**只在本局在场的席位间循环**） | `balance.selection.characters[].index` |
| 热座交接 | 轮到下一人类席前**必须显式「开始回合」确认**（遮蔽他人情报，防误操作）；AI 回合自动播放 | 设计意图 |
| 独立性 | 每席位独立：赛道位置 / 圈数 / 金币 / 人手 / 武器 / 领地 / 驻军 / 建筑 / 船只 / 存活态 | 设计意图 |
| 隐藏信息 | 交接遮蔽期内**不得显示他人金币 / 驻军 / 手牌**（`territory.md` §4.1「对方不知道你的兵力」） | 设计意图 |

> **不变量（v3）**：`players ≥ 2`（单人局 = 假多人，v2 缺陷）；`players + ai ≤ 5`；
> `ai ≥ 0` 可配；同局内同一席位不得既是玩家又是 AI；**在席席位 = 玩家席 ∪ AI 席**。

> **AI 决策参数**（`balance.territory.ai`，`territory_v2::ai_policy_v2` 读取；S33.6 兵力模型决策）：
> `attack_threshold: 0.6`（强舰队 → 攻占阈值）、`toll_aversion: 0.5`（弱舰队 → 交过路费倾向）、
> `upgrade_priority: 0.3`（升级加固倾向）。三值 ∈ [0,1] 相对权重，非百分比累加。

### 1.2 v3 终局规则（破产出局 / 胜负判定）

| 项 | 规则 |
|---|---|
| 破产触发 | 席位金币不足以支付应付款（过路费 / 攻占败双倍过路费）⇒ 该席破产。**实测落地口径**（`board.rs::check_match_end`）：`gold == 0 && crew == 0`（双零判据——过路费结算已把金币扣到 0，无舰队人手 = 无法再产出/参战 = 彻底出局；§1.2 表「交不起」语义由此双零判据实现，2026-11-03 S36.3 飞轮 F-9.1 锚定） |
| 破产结算 | 金币归零；**该席全部占领格变无主**；该席**出局**（不再参与回合轮转） |
| 出席后 | 跳过该席的回合；若其是当前人类席 ⇒ 立即轮到下一席 |
| 胜利 | **最后一个存活席位获胜**（所有对手均破产出局） |
| 失败 | 玩家（人类）席全部破产 ⇒ 玩家失败，对局结束 |
| 平局 | 理论上多人同时破产 ⇒ 判**无胜者**，对局结束（`victory_seat` 返回 `None`） |

> **AI 决策参数**（`balance.territory.ai`，`territory_v2::ai_policy_v2` 读取；S33.6 兵力模型决策）：
> `attack_threshold: 0.6`（强舰队 → 攻占阈值）、`toll_aversion: 0.5`（弱舰队 → 交过路费倾向）、
> `upgrade_priority: 0.3`（升级加固倾向）。三值 ∈ [0,1] 相对权重，非百分比累加。

### 1.3 v3 棋盘多席位渲染规则（同格散开 + 席位徽标）

> **2026-11-03 v3 补充（S36.1 落地）**：大富翁式多人对局的**视觉层**同格多席判定规则。

| 项 | 规则 |
|---|---|
| 同格起点 | 开局全席位同起点（`start_index`）出发；同格散开 = `seat_piece_offset(ordinal, total, radius)` |
| 散开半径 | 开局全员同格 ⇒ 必须扇出到**不可重叠**：相邻中心距 ≥ `2·radius·sin(π/n)`；单席 = 居中 `(0,0)` |

| 席位徽标 | 当前席 = 金色船 + 名牌（`scene.main_map.player_label` = 当前席视角「你」）；余席 = 暗灰小旗（`theme.isle_flag_dark` = `0x7BEF`）+ `P1..P5` 席位徽标 |
| 渲染路径 | 等距环（`render_track`）/ 大富翁环（`render_v5_ring`）/ v6 圆柱（`render_v6_proto`）/ v6 元素（`render_v6_elem`）四条主地图渲染全接，同一套 `seat_slots` 分组 |

## 2. 赛道格两类（领地格 / 功能格并存）

| 类 | 含义 | 可占领 | 落格结算 |
|---|---|---|---|
| **领地格** `territory` | 10 类海盗岛原型（岛屿 / 城镇 / 要塞） | ✓ | 按 §4 分叉（含攻占 / 多人同格） |
| **功能格** `feature` | 事件 / 卡牌 / 宝藏（武器·奴隶商人 = 事件格触发，§7）/ BOSS | ✗（**不能占领**） | **随机事件**（§6）/ 商人（§7）/ BOSS 战（§8） |

## 4. 落格结算分叉（核心规则）

落到**领地格** `T`（owner = `O`，level = `L`，驻军 = `G`）时：

| 情形 | 玩家可选 | 结果 |
|---|---|---|
| **T 无主** | ① 进入副本 | 副本胜利 ⇒ `O = 你`，`L = 1`（该类两格同时易主），**留驻军** `G`（自己定）；失败 ⇒ 无变化 |
| **T 属于他人 X** | ① 交钱（付过路费）<br>② **攻占**（进 VS 界面） | 交钱：付 `toll(T,L)` 给 X ⇒ 你通行无收益<br>攻占：**船队攻打建筑**（舰队人手+武器 vs 驻军 `G` + 建筑防御 `defense(T,L)`，`combat.md` §兵力模型）⇒ **胜**：`O = 你`，`L = 1`，重定驻军；**败**：**交双倍过路费**（惩罚） |
| **T 属于你** | ① 升级建筑<br>② 增减驻军<br>③ 领取产出 | 升级：付 `upgrade_cost(T,L)` ⇒ `L+1`（≤ 上限）⇒ 防御/产出/过路费同步提高<br>增减驻军：把 `G` 调到你要的值（**从舰队分出或调回**）<br>领取：获得该格本圈产出 `production(T,L)` |

落到**功能格**时按格类处理：海事随机事件（§6）/ 商人（§7 武器/奴隶）/ 宝藏 / BOSS（§8）。

### 4.1 驻军（人手）——**玩家自定，战略取舍**

- 占领格**必须留驻军** `G`（人手），规模由**占领者自己决定**（非公式）：守得厚 ⇒ 舰队人手少；
  守得薄 ⇒ 舰队人手多（机动）。
- **对方不知道你的兵力**（隐藏信息：舰队人手 / 驻军数对对手不可见；攻占时先看守军再决定）。
- 驻军 = 从席位人手池分出；占领格人手 + 舰队人手 = 席位总人手（守恒）。
- **不能卖占领格**（无卖出分支）。

### 4.2 产出（每格地形专属，每轮结算一次）

- 每格有**地形 + 建筑**（`map.json`/`layout` 逐格数据）：金矿 / 渔业 / 水果 / 礁石 等。
- 产出 `production(T,L)` 按**地形 + 建筑等级**算，**每一轮结算一次**（轮到该格或每圈末统一结算）。
- 路费 `toll(T,L)`：他人路过付给所有者（本圈产出归所有者，避免双吃）。

### 4.3 多人同格遭遇战（含 BOSS 战）

- 当**后到者**落到已被其他席位占的格时，后到者**决定打不打**前一个占格者（占格者 = 防守方）。
- 序列 a→b→c：`a` 先到占格；`b` 后到决定打不打 `a`；`c` 后到决定打不打 `b`（**只打前一个**）。
- 战斗 = 进攻方人手+武器 vs 守方驻军 `G` + 建筑防御 `defense(T,L)`（`combat.md` §兵力模型）。
- **败者交钱（过路费）+ 损失水手**；胜者占领（重定驻军）。双方必损（武器+水手）。
- BOSS 格（`boss_fort`）同规则：后到者可决定打不打 BOSS / 前一个占格者。
- **最后一席可选「攻击」或「和平」**（谈判通过，不战）。

### 4.4 破产（胜负判定，v3 口径）

- 交不起过路费 / 攻击败交双倍 / 事件损失后金币不足 ⇒ **破产**（金币归零，席位出局）。
- 破产席位的**全部占领格变空（无主）**。
- **不能卖占领格**（破产也不卖，直接清空）。
- **出局** = 破产席不再参与回合轮转（`TurnCycle` 跳过），其赛道会话冻结。
- **胜利** = **所有对手（AI + 其他人类席）全部破产出局** ⇒ 最后一个存活席位获胜。
- **失败** = **全部人类席均破产出局** ⇒ 玩家失败，对局结束（AI 之间谁最后活谁赢）。
- **平局** = 多人同回合破产致无存活席 ⇒ 无胜者，对局结束。
- 规则层实现 = `territory_v2::bankrupt` / `victory_seat` / `player_defeated`；**v3 起 app 层必须接线**
  （v2 实测 app 层 0 调用 ⇒ 对局永远打不完，见 §1.1 D4）。

## 5. 中央据点岛（玩家大本营）

- 中央大岛 = **当前玩家席位的据点**（可点击 → 据点菜单：建造 / 造船 / 贸易 / 升级本家）。
- 据点岛本身**不是赛道格**（不参与摇骰前进），但提供「升级本家」入口
  （`territory.home_upgrade` 与领地加固同族、同公式族）。
- 其他席位的据点不显示在中央（避免信息过载）；可在副本/攻占战里见到对方要塞。

## 6. 随机事件（海事类，每图配特有事件）

> 当前「抽卡」事件太少。改为**海事随机事件集**：常用集随游戏自带，**每张地图可配特有事件**
> （地图层数据 `map.json`/`manifest → events[]`，与 `balance.events` 常用集合并）。
> 事件落在**不能占领的功能格**（领地格不触发随机事件）；功能格**可能**触发（概率，
> **非必发生**）——风神保佑只是**示例**，事件集见下表。

| 事件 | 效果 | 来源 |
|---|---|---|
| **风神保佑** | **加速：多扔骰子一次**（额外回合）或 **随机前进 / 后退 N 格**（按事件参数二选一） | 常用 + 地图特有 |
| **翻车** | 沉船：损舰队资产（水手 / 武器 / 货物按比例） | 常用 + 地图特有 |
| **遇宝藏沉船** | +财宝（金币 / 武器） | 常用 + 地图特有 |
| **风浪** | 损舰队资产（航海事损失） | 常用 |
| **铁匠** | 花金币购买武器（见 §7） | 常用 |
| **流浪儿** | 加入队伍（+人手） | 常用 |
| **孤岛救援** | 救起水手（+人手） | 常用 + 地图特有 |
| 地图特有 | 按图自定义（如暗礁流 / 洋流 / 海市蜃楼…） | 每图 `events[]` |

## 7. 商人（每图必备）

| 商人 | 卖 | 规则 |
|---|---|---|
| **武器商人** | 武器 | **每张地图必有**；花金币买武器；**一人一把**（武器 > 水手 = 多余武器无效，瓶颈 = 水手） |
| **奴隶商人** | 水手 | 花金币买人手（水手来源之一） |

- **水手来源**：奴隶商人购买 + 随机事件（流浪儿 / 孤岛救援）+ 初始。
- **武器来源**：武器商人购买 + 随机事件（宝藏沉船）+ 初始。
- **一人一把武器**：有效武装 = `min(人手, 武器)`；武器多余无意义（没人用）；人手可 > 或 < 武器
  （多余人手 = 未武装，战力折减）。

## 8. 存档（`SaveSlot` v5）

| 字段 | 类型 | 含义 |
|---|---|---|
| `seats` | `Vec<SeatSave>` | 每席位：角色 / 类型（player/ai）/ 金币 / **人手 / 武器** / 位置格 / 船只 / 建筑 / **存活态** |
| `territories` | `map → [格索引 → {owner_seat, level, garrison}]` | 领地图（`owner_seat` = 席位下标；`garrison` = 驻军人手；无主 = 缺省） |
| `current_seat` | `u8` | 当前轮到哪个席位（热座交接用） |
| `unlocked_mask` | `u32` | S37 起 20 图口径（bit j = m(j+1) 解锁，bit 19 = CLEARED 通关位，飞轮 R4 勘误旧 u8；旧 u8 档读时高 24 位 = 0 向后兼容） |

- 迁移：v4 → v5 缺省 = 单席位 + 人手/武器 默认值 + 空领地图；旧迁移链保持不变。
- 存档必须能完整还原「谁占哪格 / 各席位金币/人手/武器/驻军 / 轮到谁 / 谁已出局」。
- **v3 新增**：`SeatSave.alive`（席位存活态，缺省 `true`）——破产出局必须能存档还原，
  否则读档后已出局席位复活，胜负判定失效。
