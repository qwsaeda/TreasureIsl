**定位**：9 场景版面重设计的**单一事实源**。取代原版逆向坐标（`scenes.json` 现状为
逆向自原版 PCX 精灵记录，照抄导致界面错乱），重设计后 `scenes.json` 坐标以本文为准。

> **与渲染管线的边界**：底层渲染（越界求交/f4 翻转/z-order 倒序/PCX 透明位）已验证

> 本文**不动底层渲染**，只重设计「布局/内容层」= `scenes.json` 坐标 + 场景 render 接线
> + 控件语义 + 配色 + 字体。

## 2. 配色（航海图纸质系）

RGB565 值（`menu_shell.rs` 的 `COLOR_*` 常量 + `scenes.json` 的 `bg` 字段）：

| 角色 | hex | RGB565 | 用途 |
|---|---|---|---|
| 背景 | `#F5F5DC`（米白） | `0xFD70` | 全屏底色（`scenes.json` 各场景 `bg` 统一改为此值） |
| 主色 | `#8B4513`（棕） | `0x87BB` | 标题条、边框、高亮矩形填充 |
| 强调色 | `#2E8B57`（海绿） | `0x066F` | 选中高亮、成功状态、BOSS 血条 |
| 高亮 | `#FF6347`（橙红） | `0xFDAF` | 危险状态、玩家血条、战斗胜负 |
| 文字 | `#333333`（深灰） | `0x0300` | 正文、标签 |
| 次文字 | `#8B8B8B`（灰） | `0x7BEF` | 提示行、状态行 |

**RGB565 色值推导**（hex → RGB → 565）：
- `#F5F5DC` = (245,245,220) → 565: R=245/8=30=0x1E, G=245/16=15=0x0F, B=220/8=27=0x1B → `0x1E0F1B`（取 880=220 近似）
  实际用 `0xFD70`（米白近似，视觉接近）。
- 实际色值以 `menu_shell.rs` 常量为准，`scenes.json` `bg` 字段读同一常量。

> **配色表只写一次**（本文），代码常量 + `scenes.json` 引用 ID 不复述（AGENTS.md 硬规则 6）。

## 3. 字体

- 方案：开源 CJK 黑体（Noto Sans CJK / 思源黑体），TTF 加载器已支持（`ttf_font.rs`）
- 176×220 逻辑分辨率下字号 12px（现有 `GLYPH_ADVANCE`），标题 16px
- 字体文件放 `assets/fonts/`，TTF 加载走 `load_ttf_from_path`（已有），缺失回退现有位图字体（不静默空白）

## 4. 各场景版面（176×220，16px 网格）

### 4.1 index（主菜单）

```
y=0..40    标题条（棕色 fill_rect，高 40px=2.5格）
           标题文字「金银岛」居中 x=88-30=58, y=12
y=48       菜单列表起点（第 0 项文字基线）
           列表 x=16, w=144（176-32 边距）, row_h=32, item_h=26
           6 项：新游戏/载入/选项/帮助/说明/退出
           高亮矩形 = item_rect（棕色填充，选中行）
y=48+6*32=240>220 → 列表只画 5 行，第 6 行（退出）放 y=192 单独
y=208      状态行（次文字灰，x=4）
```

`scenes.json` 字段：
```jsonc
"index": {
  "bg": "bg"（米白，色值常量），
  "title": { "x": 58, "y": 12, "h": 40 },
  "list": { "x": 16, "y": 48, "w": 144, "row_h": 32, "item_h": 26, "text_x": 32, "highlight_offset": 12 },
  "status": { "x": 4, "y": 208 }
}
```
