# 地图与移动系统设计

本文档涵盖：地图数据结构、地形网格几何、移动规则、据点/地标、事件分派。

---

## 1. 地图数据

### 1.1 地图清单

| 槽位 | 文件 | 网格 | cell 记录数 | 连线记录数 | 缺格 |
|---|---|---|---|---|---|
| M01 | `glmapm01.Map` | 20×20 | 399 | 75 | cell(0, 19) |
| M02 | `glmapm02.Map` | 20×20 | 399 | 125（含 4 条 M=4） | cell(0, 19) |
| M03 | `glmapm03.Map` | 15×15 | 224 | 23 | cell(0, 14) |

每个地图的 cell 记录数 = `grid_w × grid_h - 1`（恒缺 1 格）。
缺格恒为 `cell(row=0, col=grid_w-1)`（索引 `grid_w-1`），不可通行。

### 1.2 地形文件结构

```
words[0] = 0
words[1] = count = grid_w - 1          // m01/02=19, m03=14
words[2..] = stride=9 u32 记录流
```

记录流分三段：
1. **cell 记录** `grid_w × grid_h - 1` 条
2. **trailer** 1 条
3. **连线记录** N 条 + 6 词 sentinel

### 1.3 cell 记录字段

每条 cell 记录 9 个 u32：`[f0, f1, f2, f3, f4, f5, f6, f7, f8]`

| 字段 | 值 | 语义 |
|---|---|---|
| f0 | 1（使能标志） | 恒 1 |
| f1 | 瓦片索引 / 目标格 | 见连线段 |
| f2 | 0 | 恒 0 |
| f3 | 0 | 恒 0 |
| f4 | 1 | 恒 1 |
| f5 | mapinfo.ini 瓦片索引 | m01 max=44, m03 max=44 |
| f6 | `32 × (row + col)` | 等距投影 X 坐标 |
| f7 | `16 × (row + grid_w - 1 - col)` | 等距投影 Y 坐标 |
| f8 低 16 位 | `row × grid_w + col` | cell 线性索引 |
| f8 高 16 位 | 标志位 | 低字节 `≡ 1 mod 4` = 可通行 |

### 1.4 等距投影

```
iso_x = 32 × (row + col)
iso_y = 16 × (row + grid_w - 1 - col)
```

- row 增大 = iso 屏幕下移 = **南**
- col 增大 = iso 屏幕右移 = **东**

### 1.5 连线记录

每条 `[0, 0, 0, 0, 0, M, A, B, C]`：

| 字段 | 语义 |
|---|---|
| M | 连接类型，`M ∈ {2, 4}`（m02 独有 4 条 M=4） |
| A | 瓦片索引（< 49） |
| B | 等距像素 X 坐标 |
| C | 等距像素 Y 坐标（非降序排列 = painter's 绘制序） |

连线目标格满足：`|Δcol| ≤ 1` 且 `Δrow ≤ 0`（同列或邻列，绝不向下）。
类别码 1..=9 全覆盖（9 种路线类别）。

文件尾固定 6 词 sentinel `[0, 0, 0, 0, 0, 2]`。

## 2. 移动规则

### 2.1 方向枚举

| 方向码 | 枚举 | Δ(row, col) | 探测优先级 | 方向位 |
|---|---|---|---|---|
| 0 | North（北） | (-1, 0) | 4（兜底） | 8 |
| 1 | West（西） | (0, -1) | 3 | 4 |
| 2 | South（南） | (+1, 0) | 1（优先） | 2 |
| 3 | East（东） | (0, +1) | 2 | 1 |

方向位掩码编码：1=西/2=南/4=东/8=北。

### 2.2 可通行性

格子标志字节（+22）低 2 位：
- `& 3 == 1` = 可通行（普通可走格）
- 其余 = 不可通行（阻挡/据点/其他）

越界格子一律视为不可通行。

### 2.3 单步移动

```
输入：(grid_w, grid_h, blocked[], pos, direction d)
delta = d.delta()         // North=(-1,0), West=(0,-1), South=(1,0), East=(0,1)
new_row = pos.row + delta.0
new_col = pos.col + delta.1

if new_row < 0 || new_col < 0:
    return None           // 负坐标越界
if new_row >= grid_h || new_col >= grid_w:
    return None           // 正坐标越界
if blocked[new_row * grid_w + new_col]:
    return None           // 阻挡

return Some(GridPos { row: new_row, col: new_col })
```

### 2.4 走 N 步

```
输入：(terrain, pos, direction d, steps N)

cur = pos
walked = 0
for i in 0..N:
    match oracle_move(terrain, cur, d):
        Some(next) → cur = next; walked += 1
        None → break      // 撞墙/越界，停在原地

return (cur, walked)
```

返回 `(终点, 实际走的步数)`。

### 2.5 自动方向选择（AI 漫游）

当玩家不指定方向时，AI 按优先级探测可达方向：

```
oracle_pick_dir(terrain, pos):
    if 当前格本身不可通行:
        return None

    // 按优先级尝试：南 → 东 → 北 → 西
    for d in [South, East, North, West]:
        if oracle_move(terrain, pos, d) is Some:
            return Some(d)

    return None            // 全方向不可通行
```

### 2.6 随机漫游分支

方向位全 0 且回落仍 0 时（所有方向都不可通行）：
```
rand() % 4   // 随机选 4 方向之一，绕开已屏蔽位
```
此分支由 RNG 模块控制（随机序列归 S3.12）。

### 2.7 单位初始定位

```
row = cell_index % grid_w
col = cell_index / grid_w
```

cell 索引 = `row × grid_w + col` 的逆运算，与 f8 低 16 位公式互逆。

### 2.8 轨迹记录

每步移动后，新格指针插入 `unit+184` 轨迹链表。
出口 `unit+128` = 本步方向位 v8（7/11/13/14 = 方向状态码，对应精灵朝向帧）。

## 3. 据点/地标

### 3.1 据点判定

```
oracle_at_landmark(landmarks[], pos):
    return landmarks 中存在 (r, c) 使得 r == pos.row && c == pos.col
```

### 3.2 据点资源结算

据点命中时：

1. 遍历精灵匹配场景 id（`a1+8`）。
2. 命中 → 累加 `*(u16*)(region+22)` 资源值（上限 999 = `0x3E7`）。
3. 未命中 → `00048654:据点定位` 扣减（贸易/建设消耗）。
4. 资源值为 0 且计数 > 1 → 补 1（保底机制）。

### 3.3 据点触发概率

```
rand() % 100 + 1 > 40   // 40% 命中率区域匹配
```

区域匹配：`*(region+24) + 4 * *(region+48) - 4 == 0x10000` 或概率命中。

### 3.4 据点显示

命中据点 → 装载 `ui.pak + msgl.Map` 显示据点名：

```
swprintf(buffer, "%s：%s", 标题, 据点名)
```

据点名称来源：`word_7FB48` 据点名称表（u16 宽字符，NULL 终止）。

## 4. 事件码分派

### 4.1 事件码计算

```
event_code = (*(u8*)(*(u32*)(ctrl+12) + 22) >> 2) + 1
// 高 6 位 + 1，值域 1..31
```

读取控件 `ctrl+12` 槽所指向事件描述符对象的 +22 字节，高 6 位为事件 id。

### 4.2 主分派表

主地图帧更新 `主地图帧更新` 行 1709 `switch(event_code)` case 1..8：

| 事件码 | 行为 | 目标场景 | 细节 |
|---|---|---|---|
| 1 | 据点/地标 | Msgl | `据点定位` 定位 + `据点布局` 布局 + `trade` 判定命中 → `ui.pak+msgl.Map` 显示名；否则探索推进 `OnSysCommand`/`0002101C:帧更新;00029110:场景管理器;00048AC0:资源读取;0004D1B0:资源写入` |
| 2 | 面板/对话框 | Msgm | `0002101C:帧更新` 设坐标 + `0002101C:帧更新` 定位 → `ui.pak+msgm.Map` |
| 3 | 卡牌/战斗准备 | 无场景 | `rand()%25+1` 生成 event_id；{4,13,14,15} 重映射 +4；`cards` 存目标；门控 `库存 >= 10` → 装 `card.Map`+`bigcard.Map`，`a1+716=4` |
| 4 | 贸易/货物 | Msgl | `0002101C:帧更新` 判 + `rand()` 哈希选商品 + `贸易操作验证` 结算；结果 `==14/22` → 结束帧 → `ui.pak+msgl.Map` |
| 5 | 卡片翻转 | Msgm | `0002101C:帧更新` + 动画序列 → `场景切换触发器(…,3)` |
| 6 | 战斗触发 | Vs | `0002101C:帧更新` 判 → `战斗对象构造` 建 vs 对象 + `ui.pak+vs.Map` + 初始化 → `a1+716=25` |
| 7 | 消息/提示 | Msgm | `0002101C:帧更新` 判 + `探索格` 方向计算 → `ui.pak+msgm.Map` |
| 8 | 退出/返回 | Msgs/Msgm | 虚调用 `+80` 判：`==0` → `msgs.Map`；`!=0` → `msgm.Map`（+112 置 1） |

### 4.3 事件码 9..31

主分派无 case（由场景管理器 `场景管理器帧更新总控` 排队事件消费路径处理）。
排队事件码 1..27（`00029110:场景管理器` 哨兵 27）。

### 4.4 事件 id 回填

事件 id 不在 .Map 记录中。由运行时场景逻辑（`主地图帧更新`/`场景管理器帧更新总控`）回填到精灵对象 +22 字节。

回填点 41 处：
- `0002101C:帧更新(ctrl, id)` → 写入 ctrl+16 队列
- `00029110:场景管理器(ctrl, id)` → 写入 ctrl+28 队列
- `00029110:场景管理器(ctrl)` → 队列头读取（空 → 返回 27 哨兵）

`主地图帧更新` 写入 id ∈ {1,2,3,4,5,11,12,13,17,18,19,20,21,24,25,26,27}。
`场景管理器帧更新总控` 写入 id ∈ {6,7,8,9,10,14,15,16,22,23}。
