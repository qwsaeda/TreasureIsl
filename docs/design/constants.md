## 7. 场景与事件码

### 7.1 场景状态码

> 场景状态码（§7.1）与场景码切换值（§7.4）为两套独立域：状态码 4 = 过场/坐标切换（运行时态），
> 场景码 4 = 回主地图（场景装载目标）。同名数值，语义不同。

| 状态码 | 语义 |
|---|---|
| 0 | 主菜单态 |
| 2 | 场景卸载中 |
| 3 | 回主菜单 |
| 4 | 过场/坐标切换 |
| 25 | 战斗态 |
| 26 | 过场动画 phase 26 |
| 27 | 过场动画 phase 27 |

### 7.2 触发事件码

> 触发事件码（§7.2，场景管理器 switch 值）与主地图事件分派码（§7.5）为两套独立体系：
> 触发码 3 = 回菜单，分派码 3 = 卡牌随机数（同名数值，语义不同）。

| 触发码 | 含义 |
|---|---|
| 0 | 无触发 |
| 1 | 进战斗 |
| 2 | 战斗结束 |
| 3 | 回菜单 |
| 4 | 触发过场 |
